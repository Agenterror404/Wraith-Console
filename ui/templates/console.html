HOW IT WORKS

Every tool call is scope-checked server-side before it runs — an out-of-scope target is refused and never sent. Add the hosts you're authorized to test under Scope, then drive any of the ten tools from Tools. Confirmed findings (with proof) collect under Findings and export to a markdown report.
